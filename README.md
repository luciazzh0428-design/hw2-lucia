# HW2 - LLM Business Writing Prototype

## 1. Workflow
Customer support email response drafting

## 2. User
Customer support agent in an e-commerce company

## 3. Input
Customer messages such as complaints, refund requests, or general inquiries

## 4. Output
A professional, polite, and helpful email response

## 5. Value
This task is repetitive and time-consuming. Automating first drafts can:
- save time
- improve consistency
- help agents respond faster

## 6. Why this matters
Customer support quality directly affects customer satisfaction and brand reputation. A good first draft can significantly improve efficiency while maintaining quality.
